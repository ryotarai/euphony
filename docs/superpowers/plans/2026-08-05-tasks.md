# Tasks Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or superpowers:subagent-driven-development) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a durable Tasks workspace that covers create, AI refinement, agent start, agent communication, terminal navigation, automatic agent updates, and completion.

**Architecture:** Add a focused `internal/tasks` domain package with a SQLite-backed repository, task lifecycle service, event subscriber, and HTTP handlers. Reuse the existing `control.Service` for terminal and agent operations, and extend `internal/agentsummary` with a structured refinement runner using the configured Claude/Codex command. Add a controlled React `TasksView` and connect it to App state, the event stream, and the new sidebar-first navigation item.

**Tech Stack:** Go 1.24, `modernc.org/sqlite`, existing control/event hub, existing Claude/Codex command runner, React, TypeScript, Vitest, Testing Library, Playwright.

## Global Constraints

- Communicate with users in Japanese; write code, tests, and repository documents in English.
- Preserve existing Agents, terminal selection, attention, and terminal source behavior.
- Persist arbitrary terminal bytes losslessly; task text is UTF-8 JSON with bounded field sizes.
- Use `apply_patch` for file edits and keep all implementation in `tmp/worktrees/tasks` until verification and merge.
- Use TDD: write each failing test, run it red, implement the minimum behavior, run it green, then commit.
- Run frontend E2E with one worker and an isolated database/port.
