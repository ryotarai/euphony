# macOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a self-contained 'bin/Euphony.app' that starts the existing Go server and displays the existing React workspace in a native macOS WebKit window.

**Architecture:** Keep 'bin/euphony' as the existing CLI/browser entry point. Add an AppKit/WebKit shell and bundle the Go executable as 'Contents/Resources/euphony-server'. The shell starts the server on a loopback ephemeral port, reads the published URL from a readiness file, loads the tokenized URL, and terminates the child server when the app quits.

**Tech Stack:** Go 1.24, Swift/AppKit, Swift/WebKit, React/Vite assets already embedded by the Go server, Make and Bash.

## Global Constraints

- The existing CLI and browser startup behavior must remain available.
- The desktop server must bind only to '127.0.0.1' and must not reuse the user's normal TCP port.
- Node.js must not be required when the built app is launched.
- The app build target is macOS-only and must report a clear error when 'swiftc' is unavailable.
- Do not add Wails or another desktop runtime in this iteration; the current WebSocket terminal transport remains unchanged.
- Do not add signing, notarization, automatic updates, App Store packaging, or a custom icon.
- All code and repository documents are written in English; user-facing progress is communicated in Japanese.
- All implementation changes stay in '/Users/ryotarai/work/euphony/tmp/worktrees/macos-app' until they are committed and merged.

In 'cmd/euphony/main.go':

~~~go
func listenTCP(address string) (net.Listener, string, error) {
	listener, err := net.Listen("tcp", address)
	if err != nil {
		return nil, "", fmt.Errorf("listen on %s: %w", address, err)
	}
	return listener, listener.Addr().String(), nil
}

func writeReadyFile(path, baseURL string) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o700); err != nil {
		return fmt.Errorf("create readiness directory: %w", err)
	}
	temporary, err := os.CreateTemp(filepath.Dir(path), ".euphony-ready-*")
	if err != nil {
		return fmt.Errorf("create readiness file: %w", err)
	}
	temporaryPath := temporary.Name()
	defer os.Remove(temporaryPath)
	if err := temporary.Chmod(0o600); err != nil {
		_ = temporary.Close()
		return fmt.Errorf("protect readiness file: %w", err)
	}
	if _, err := io.WriteString(temporary, baseURL+"\n"); err != nil {
		_ = temporary.Close()
		return fmt.Errorf("write readiness file: %w", err)
	}
	if err := temporary.Close(); err != nil {
		return fmt.Errorf("close readiness file: %w", err)
	}
	if err := os.Rename(temporaryPath, path); err != nil {
		return fmt.Errorf("publish readiness file: %w", err)
	}
	return nil
}
~~~

Import 'net', bind the TCP listener before 'server.New', use its actual address
for 'HookURL' and 'browserURL', call 'Serve(listener)' instead of
'ListenAndServe', and publish 'http://' plus the actual address after both
servers have started. Only publish when 'EUPHONY_READY_FILE' is non-empty, and
remove that file during shutdown. Close the already-bound listener if any
later startup step fails.

- [ ] **Step 2: Implement the AppKit delegate and process lifecycle.**

Implement 'EuphonyApp.swift' with these concrete behaviors:

- Create an 'NSApplication' with a regular activation policy and a standard
  application menu containing 'Quit Euphony' ('⌘Q') and a Window menu.
- On launch, locate 'euphony-server' with
  'Bundle.main.url(forResource: "euphony-server", withExtension: nil)'.
- Generate a token from two UUID strings and a unique readiness path below
  'FileManager.default.temporaryDirectory'.

  stderr to '~/Library/Logs/Euphony/app.log'. Use a file handle rather than an

  non-empty 'http://127.0.0.1:<port>' URL appears, load it with a 'token' query
  item in 'WKWebView'. The readiness file is only published after the Go
  listener is bound, so the URL is the selected port.
- Create a titled, closable, miniaturizable, resizable 1280x820 window with a
  640x480 minimum size, center it, activate the app, and make it key.
- If the server binary is missing, 'Process.run()' fails, the process exits
  before readiness, or the timeout expires, show an 'NSAlert' titled
  'Euphony could not start', terminate the child, remove the readiness file,
  and quit.
- Set 'applicationShouldTerminateAfterLastWindowClosed' to 'true' and call
  'terminate()' on the server process in 'applicationWillTerminate'.
