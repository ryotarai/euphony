# No-Authentication Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an explicit `EUPHONY_AUTH_MODE=none` mode that skips Euphony authentication without changing the secure default.

**Architecture:** The Go server normalizes an auth mode and conditionally applies the existing bearer middleware. A public auth-config endpoint lets the React app distinguish no-auth from a missing token, while the existing terminal ticket remains the WebSocket credential. Empty hook tokens omit the header so agent metadata continues to flow in no-auth mode.

**Tech Stack:** Go `net/http`, React 19, TypeScript, Vitest, Go tests, shell scripts, Markdown.

**Spec:** `docs/superpowers/specs/2026-08-27-auth-none-design.md`

## Global Constraints

- `EUPHONY_AUTH_MODE` defaults to `token` and only the exact value `none` disables authentication.
- Token authentication, generated-token startup, terminal tickets, and existing API behavior remain unchanged by default.
- No-auth mode is opt-in and must be documented as unsafe outside a trusted local network.
- Production code is added only after a test demonstrates the missing behavior.
- Existing unrelated worktree changes must remain untouched.

- Modify: `cmd/euphony/main_test.go`

- Produce `resolveAuthMode(string) (server.AuthMode, error)`.
